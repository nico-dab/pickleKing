# Future Features

## Mobile Admin Enhancements
- Swipe-to-reveal trays for +W/+L actions to reduce on-screen buttons.
- Action sheet modals for rename, reset, and remove player workflows.
- Quick filter pill bar (Singles, Teams, Favorites) under the header.
- Floating `+ Add Player` button opening a full-screen progress-aware form.

## Progressive Web App
- Manifest + platform icons to enable Add-to-Home splash screens.
- Workbox caching with `StaleWhileRevalidate` for leaderboard shell and background sync for stats.
- Offline mutation queue with status badges for pending updates.
- Push notification opt-ins for tournament alerts and match reminders.
- Lighthouse PWA audit to track installability and performance scores.

## Design Exploration
- High-fidelity mobile mocks in Figma covering leaderboard states.
- Service worker implementation once interaction patterns stabilize.

## Player Personalization
- Nickname field so players can choose a preferred display name beyond first-name defaults.
